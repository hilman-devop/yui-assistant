## Yang dikerjakan sesi sebelumnya

1. **WA bridge hidup total** — root cause bertingkat: wacli butuh `--webhook-allow-private` (SSRF guard localhost); pesan HP utama datang sebagai `SenderJID @lid` + `FromMe=false` → whitelist LID; HP kedua (ilham) masuk `allow_numbers`; JID ber-suffix device (`:7@lid`) → strip `:device`
2. **Bug int dari router** — Cloudflare kirim token angka sebagai JSON number → `"".join()` crash → coerce `str()` di boundary LLM (`core/llm.py`)
3. **Scan model menyeluruh** (`tests/probe_all.py`, 8 kandidat 2 endpoint): qwen3.6-27b tercepat (0.22s) tapi bocor `<think>` → **gpt-oss-120b** (0.38s, reasoning tidak bocor) menggantikan cf llama-3.1-8b
4. **Failover chain** — 3 key Groq cadangan diambil dari DB 9Router (`%APPDATA%/9Router/db/data.sqlite`, tabel providerConnections, plaintext) → `.env`; `FailoverLlm` pindah endpoint kalau 429/401; diuji dengan key rusak
5. **browser_task** — delegasi ke session `kimi web` via WS JSON-RPC; temuan: session web interaktif = tool call **nunggu approval** (gantung 45 mnt) → auto-jawab `approve_for_session`; turn gantung di-cancel via WS `cancel`
6. **Anti-overtrigger** — "halo yui" sempat memicu browser_task (pattern-match history penuh perintah google) → aturan eksplisit di SYSTEM_PROMPT + deskripsi tool
7. **Bersih-bersih** — hapus: `webbridge-req-nav01.json` (temp WebBridge), `check_t10` (9Router-era, digantikan e2e+probe_all), 5 probe lama (`probe_latency/probe_models/probe_tools/scan_models/list_models`), `transcribe_fast`+`fast_size` (dead code sejak single-pass ASR); README.md + SESSION.md dibuat

## Known issues / catatan

- Whisper kadang halusinasi di noise ambient → dimitigasi RMS gate (<0.01 skip) + wake-gate; kalau TV/obrolan keras masih tembus, opsi: naikkan threshold RMS
- Kecil, sengaja belum diperbaiki: path model VAD relatif cwd; `Memory.set_fact` read-modify-write di luar lock; `_SENT_END` motong "10:30"; FastAPI `on_event` deprecated
- `browser_task` auto-approve SEMUA tool call di session Kimi — kalau mau batasi (mis. blokir posting), filter `action` di `_wait_selesai`
- Zombie wacli/python kalau bunuh Yui paksa → store lock; beresin: kill proses `wacli.exe` + pastikan port 8765 bebas sebelum restart
